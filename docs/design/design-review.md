## 설계 검토에서 보완한 부분

| 쟁점 | 반영한 결정 |
| --- | --- |
| 기억을 자동으로 다 수집한다는 오해 | 호스트가 전달한 발췌와 허용 파일로 입력 범위 명시 |
| 모델이 승인 내용을 잘못 이해할 위험 | 의도 기록·provenance·실제 호스트 권한 분리 |
| Laya가 여러 작업에서 중복 적재될 위험 | 단일 적재 소유권, 경쟁 시 검색 모드 |
| 한국어 1~2자 검색 누락 | trigram 외 경로·제목·제한된 부분 문자열 검색 |
| 원문 변경 중 모델 결과 도착 | revision 재검증, 오래된 결과 폐기·partial |
| 저장은 됐으나 응답이 유실된 경우 | mutation ID 재조회·같은 작업 중복 방지 |
| 엔진별 confidence의 다른 의미 | 원래 분포·정의·프로필 버전 보존 |
| 번역이 승인·부정을 바꾸는 문제 | 원문 보존·선택형 번역·언어별 검증 |
| 삭제 후 캐시·재전송에서 재노출 | 파생 참조 삭제·replay 가림·물리 소거 범위 분리 |
| 사례 30개가 실제 평가로 오인될 위험 | 합성 설계 예시와 실제 평가 세트 구분 |

## 확인 범위

공식 MCP·Codex 연결·hooks·SQLite FTS5·WAL 문서를 재확인하고 필요한 계약에 출처 연결
이전 대화에서 조사한 공개 모델·PDF·X 근거를 기존 문서에서 재사용
설계 문서의 제목·상대 링크·코드 블록 검사를 수행하고 JSON 예제 문법·도구 목록·사례 개수 일치 확인
Markdown 9개 파일의 제공된 검사 통과, JSON 예제 3개 파싱 성공, P01~P30과 도구 8개 목록·상세 절의 대응 확인
이 검사는 도구 schema의 실행 검증이나 실제 엔진 품질 검증을 포함하지 않는 범위

## 미검증 범위

프로그램 구현, 모델 다운로드·추론, Desktop 연결, 작업 복원 시연, RAM·GPU 실측, 한국어 실제 평가 미수행
현재 권한에서 하드웨어 조회가 거부되어 장비별 기본 엔진은 미선정
Mermaid CLI를 실행할 경로가 확인되지 않아 도식은 구조·참조 검토까지만 수행하고 실제 렌더는 미검증
제품 기본값과 시간 목표는 실측 결과가 아닌 첫 구현의 제안 값
