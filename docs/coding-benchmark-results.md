## 실행 방법과 범위

[사전 계획](coding-benchmark-plan.md)에 따라 승인된 보조 에이전트 6회, 동시에 최대 2개 실행
모든 실행은 새 문맥의 `gpt-6-astra`, 별도 모델 override·현재 대화 이력 복사 없이 시작
동일 출발 코드의 복사본에 결함 하나씩 주입하고 과제당 `off`와 `observe` 비교
지정한 파일 하나만 수정하도록 지시하고 실행 전후 전체 파일 hash로 변경 범위 확인
OS 수준 격리가 아닌 경로 분리·작업 지시·변경 검증 방식

영어 작업 지시와 같은 한국어 정책 발췌 4개를 두 조건에 제공
`observe`에만 실제 OpenJev 관련성·표현 길이 판단 추가, 원문 제외·축약·번역 없이 유지
정답 구현이나 숨긴 채점 파일을 입력에 포함하지 않는 구성
모델 어댑터의 정책 주석 효과를 보는 비교이며 전체 MCP 검색 경로·active 선별의 종단 평가와 구분

모델·가중치 revision·v2-2 지시문은 유지하고 평가 profile과 runtime hash를 별도로 고정

## 발견한 제품 결함과 수정

기존 JSON 파서는 `NaN`·`Infinity`를 거절하지만 정상 숫자 문법인 `1e999`를 Python의 무한대로 변환해 입력 단계 통과
최상위 양수와 중첩 음수 사례에서 입력 오류 종료 코드 2 대신 서비스 처리 후 종료 코드 1을 반환하는 실패 재현
CLI 입력 객체를 순회해 모든 깊이의 비유한 float를 엔진·저장소 초기화 전에 거절하도록 수정
유한한 큰 지수·작은 지수·한국어 입력과 기존 크기 제한 유지

해당 제품 수정은 동결된 평가 복사본·채점 기준과 별도이며 이번 6회 결과에 소급 반영하지 않은 변경
CLI 검사 9개 통과, 제품 전체 115 passed·1 skipped와 정적·형식 검사 통과
skipped는 기존 Windows 심볼릭 링크 생성 권한 검사

채점 도구에서는 상위 pytest 설정이 복사본 대신 원본을 읽는 문제를 먼저 발견
실패 재현 후 복사본 전용 설정과 외부 conftest 차단으로 수정, 결함 주입본이 실제로 실패하는지 확인 후 에이전트 실행
평가 입력·채점 파일 변경과 재사용 디렉터리 덮어쓰기를 거절하는 보호 검사 추가

## 판단 품질과 남은 조건

이전 `challenge-3-ko/en`은 삭제 정책의 명령문과 삭제 완료 주장을 비교해 정답 해석이 모호한 항목으로 별도 감사 기록
동결된 자료와 점수는 수정하지 않고 독립 검토 대상으로 유지
관리자 추가 인증 사례 `validation-11-en`의 v3 false supports 3회는 명확한 회귀로 유지
평가 작성 에이전트나 이번 보조 에이전트를 사람 검토자로 표시하지 않는 기준

이번 결과로 확인한 범위는 독립 실행·고정 검사에 따른 실제 수정 성공과 호스트 사용량 수집
사람이 검토한 미사용 자료, 언어·목적별 품질, 중요 회귀 0건, 전체 비용·지연을 포함한 반복 평가와 자동 선별 효율은 남은 조건
현재 Desktop MCP에서도 운영 shadow 설정·목적별 승격 false 확인
평가 후 두 Modal 앱 stopped·컨테이너 0개, 운영·평가 세션 모두 unavailable 확인
