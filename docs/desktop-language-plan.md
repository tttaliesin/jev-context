# 한영 전환과 영문 README — 0.5.0

1. 앱 전용 한국어/영어 메시지 사전을 만들고 정적 화면, 동적 상태, 접근성 설명, 오류 안내에 적용한다. 작업 원문·경로·설정/Skill 미리보기는 번역하지 않는다.
2. 상단과 첫 연결 창에 `한국어 / English` 선택을 제공한다. 기본값은 기존 한국어이며 앱 사용자 설정에 저장한다. 언어 변경은 화면만 갱신하고 작업 선택·필터·온보딩 입력을 유지한다.
3. 날짜 표시는 선택 언어를 따른다. 기본 파일 선택 창의 제목과 앱 오류 안내도 같은 언어를 사용한다. 운영체제 자체의 버튼 언어는 OS 설정을 따른다.
4. 연결 확인 문구는 같은 요청 ID를 유지하며 선택 언어로 표시·복사한다. 설정 원문과 설치할 Skill의 언어는 변경하지 않는다.
5. 한국어 README를 유지하고 동등한 영문 `README.en.md`와 상호 이동 링크를 추가한다.
6. 메시지/치환 변수 검사, 한국어 회귀 검사, 실제 Electron 앱의 왕복 전환·재실행·오류·온보딩·좁은 창을 검증한다. 패키징 후 커밋·원격 반영한다.

## 구현

- `desktop/locales.js`: 한국어 원문 키 기반의 영어 메시지 사전. `{0}` 등의 값은 문자열로만 치환한다. 기존 서비스 오류는 알려진 메시지에 한해 표시 단계에서 번역하고, 알 수 없는 진단은 원문을 보존한다.
- `desktop/renderer/i18n.js`: 정적 텍스트·접근성 속성, 언어 선택, `html.lang`을 관리한다. 동적 상태는 캐시된 상태로 다시 그린다. 언어 변경 자체는 모델/작업 서비스 요청을 만들지 않는다.
- 언어는 Electron 사용자 데이터 폴더의 `settings.json`에 `ko` 또는 `en`으로 저장한다. 기존 프로젝트·Python 경로를 함께 보존한다. 저장 실패 시 화면 언어를 유지하고 다시 시도할 수 있도록 안내한다.
- 상단과 연결 안내 창에서 모두 바꿀 수 있다. 작업 선택·필터·온보딩 단계·입력·오류·오래된 상태 표시를 유지한다. 작업 원문과 설정·Skill 미리보기에는 번역을 적용하지 않는다.
- 확인 문구는 같은 요청 인자를 그대로 둔 채 지시문만 번역한다. 복사 내용은 현재 표시 언어를 따른다.
- `README.en.md`에 설치, 앱 사용, 도구 계약, 검증 한계와 문서 목록을 제공하고 한국어 README와 연결했다. 상세 설계 문서는 한국어임을 명시했다.

## 검증 — 2026-09-27

- `scripts/test_locales.cjs`와 창 상태 테스트: 총 11개 통과. 문구 누락·치환 변수 일치·진단 원문 보존·확인 요청 인자 보존 검사 포함.
- `scripts/test_desktop_states.cjs`: 기존 한국어 42개, 영어 모델 상태 8개와 오래된 상태 유지 1개를 합친 51개 화면 검사. 테스트 자료의 한글 경로는 번역 누락과 구별하여 원문 유지 여부를 별도로 검사한다.
- 실제 패키징 앱 `scripts/test_desktop_language.cjs`: 한국어↔영어, 양 언어 재실행 저장, 필터와 한글 작업 원문 유지, 메뉴·단축키·날짜, 온보딩 단계/입력/미리보기 보존, 오래된 미리보기 오류의 왕복 번역, 확인 문구 표시/복사와 요청 ID 보존, 잘못된 언어 거부, 설정 저장 실패 시 원래 언어 유지, 프로젝트 선택 후 Python/언어 설정 유지 통과. 페이지 오류 0개.
- 최소 창 940×690에서 125% 확대 시 논리 화면 752×552 안에 안내창과 하단 버튼 유지. 모델 worker/broker 없음, 수집 자료 0개 확인.
- 기존 실제 앱 온보딩 검사 통과: 설치·MCP 서버 통신·SDK 확인 요청 수신·복원. 실제 Codex 호스트 재연결 검증과는 구별한다.
- `scripts/check.py`: Ruff lint/format 통과, pytest **287 통과·2 제외**. 제외는 Windows 링크 생성 권한 조건이다.
- 실제 앱의 기존 UX 재실행 검사도 통과했다. 최종 패키지의 16개 파일이 소스와 바이트 단위로 일치한다.
- 두 README의 로컬 링크 148개가 유효하고, 각각 1152px·390px 폭에서 이미지 로드와 가로 넘침 없음 확인. 영문판의 실제 화면과 레이아웃을 시각적으로 검토했다.

앱 검사는 격리된 임시 프로젝트와 사용자 설정 폴더에서 실행했다. 파일 선택창의 응답만 대체했으며 Electron·IPC·Python 서비스·설정 파일은 실제로 사용했다. 모델 실행은 요청하지 않았다.
