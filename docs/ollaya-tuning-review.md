# 2차 튜닝 계획 사전 검토

2026-09-28. 설치·모델 추론 전에 작성자가 수행한 자체 검토다. 독립 검토자나 사람 검토를 받았다는 의미가 아니다. [확정 계획](ollaya-tuning-plan.md).

| 지적 | 보완 및 판단 |
|---|---|
| 1차 최종 사례가 이미 노출됨 | 기존 60개 모두 개발로 전환하고 새 60개를 최종 진단으로 고정 |
| 질문 변형만 늘리면 과적합 가능 | Laya 6개, decider 모델당 2개로 사전 한정. 최종 결과로 후보 추가 금지 |
| 다른 모델의 한국어 지원이 불분명 | decider의 영어 안내를 명시하고 한국어 판단은 실험으로만 확인 |
| 더 큰 모델이 메모리를 압박할 수 있음 | 현재 가용 RAM 약 10.96 GiB. decider:0.8b를 우선 실행하고 2b는 실제 준비 시 12 GiB 조건을 만족할 때만 다운로드·실행 |
| 분해는 호출 수·지연을 늘림 | 문항별 시간이 아닌 사례 전체 15초 제한과 전체 p95로 판단 |
| 분해 결과에 원래 분류 확률이 없음 | 최종 확률을 꾸며 만들지 않고 하위 결과와 보수적인 decision score만 기록. NLL은 분해 구성에서 계산하지 않음 |
| 불완전한 후보가 빠른 것으로 선택될 수 있음 | 모든 개발 사례를 정상 관측한 후보만 선택 가능. 실패·미실행은 표와 분모에 유지 |
| 여러 모델 동시 운영은 과거 자원 문제를 되풀이함 | 각 실험 모델 순차 실행. 합격하더라도 이번에는 단일 구성의 통합 후보로 판정 |
| Modelfile만으로 입력 변환·합성을 재현할 수 없음 | 질문 파일 외에 입력 변환과 합성 규칙을 가진 실행 도구를 제공하고, Modelfile의 범위를 명시 |
| 튜닝 실패를 Ollaya 전체의 실패로 오해 가능 | 모델·설정별 결과와 미실행 범위, 추가 학습의 필요 조건을 쉬운 설명으로 함께 보고 |

위 수정은 실행 전에 계획에 반영했다. 최종 진단·기존 SemIf 비교·결과 문서화까지 진행 가능하다. 실험 결과 자체가 제품 승격 승인은 아니다.
